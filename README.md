### STEPS TO PRACTICE

1. Install uv
```
pip install uv
```
2. Create a venv
```
uv venv ragenv
```
3. Activate the venv
```
basicragenv\Scripts\activate
```

### STEPS FOR GIT AND GITHUB
1. Install Git
2. Sign up on GitHub
3. Make a repo on github and don't touch anything
4. Make a .gitignore file
5. Commands
```
git add .
```

```
git commit -m "some message"
```
```
git push
```
